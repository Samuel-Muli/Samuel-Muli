## 👋 About Me

I'm a **Mechanical Engineer** who codes — I love the intersection of engineering thinking and creative development. I build personal projects ranging from portfolio websites to Python automation tools, always chasing the perfect balance between form and function.

- 🔭 Currently polishing my **[portfolio website](https://muli-samuel.onrender.com/)**
- 🌱 Exploring full-stack development with **React, Python & JavaScript**
- 🛠️ I build tools that solve real problems — for myself and others
